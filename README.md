## 📌 Objective
Analyze historical sales data to identify trends and seasonality and build a forecasting model to predict future sales, presented through an interactive dashboard for business decision-making.

## 🚀 Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- Statsmodels / Prophet
- Streamlit
